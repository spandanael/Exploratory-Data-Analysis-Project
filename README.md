# Exploratory Data Analysis (EDA) Project

## Project Overview
This project performs Exploratory Data Analysis (EDA) on the Titanic dataset to identify patterns, trends, and relationships between different features. Statistical summaries and visualizations are used to gain insights into the data.

## Tools and Technologies
- Python
- Google Colab
- Pandas
- Matplotlib
- Seaborn

## Project Workflow
- Loaded the Titanic dataset
- Examined the dataset structure
- Generated statistical summaries
- Handled missing values
- Performed exploratory analysis
- Created visualizations
- Identified key insights

## Visualizations
- Passenger Class Distribution
- Gender Distribution
- Age Distribution
- Survival Distribution
- Survival by Gender
- Survival by Passenger Class
- Fare Distribution
- Correlation Heatmap

## Outcome
The analysis successfully revealed important trends and relationships in the Titanic dataset, improving understanding of the data through visualization and statistical analysis.
